## 教材の対応付け

[a1-learning-units.json](a1-learning-units.json) はA-1の既存738問を181の主論点に対応付ける分類表。公式過去問570問と補強168問を含み、問題IDは1回だけ登録する。既存の分野・タグ・調査論点・解説を参照し、問題文形式の見出しを概念名へ整理した。全選択肢に出てくる知識を習得済みにするのではなく、主に確認する論点を1つ割り当てる。

例：

- 「正規化」「第2正規形」「第3正規形」「DB正規化」は同じ主論点。
- DB正規化、キーと参照整合性、SQLの集約、SQLの結合は別の主論点。
- DNSキャッシュとCPUキャッシュ、DBのリストアと連結リスト、オブジェクト指向の汎化と機械学習の汎化は別の主論点。
- 年度をまたぐ同じ問題群は、同じ主論点に対応させる。

問題IDによる対応を優先し、履歴に保存された古い分野名やタグにも同じ分類を適用する。`aliases` は既存教材中で対応先が一意になるラベルだけを収録し、表記揺れや新しい取り込みの完全一致に使う。本文・解説への実行時の正規表現照合や、単なる問題IDを独立論点として数える処理はしない。

追加教材では既存主論点へ問題IDを登録するか、必要なら主論点を追加する。明示的な `reviewConcepts` を持つユーザー教材はその主概念を利用する。分類できない教材は「分類待ち」に表示し、未着手論点の演習・論点数から除外する。問題文形式のタグだけで論点数を水増ししない。

## 着手判定と出題

同じ科目の採点済み履歴のうち、選択肢または自信度を入力した回答を使う。選択肢なしで「わからない」を確定した場合も含む。セット一括提出で未回答のまま不正解になった問題は含めない。取り消したセットの未採点問題も元の履歴処理に従って含めない。

主論点に1つでも回答があれば着手済み。同じ分野でも主論点が違えば未着手として出題できる。退役・未検証の教材への回答も着手判定に含めるが、それだけでは定着候補を成立させない。

検証済み・模試用確保対象外の教材から、着手済み主論点と既出問題のID・別版・問題群・同内容を除外する。各分野から順に選び、異なる主論点を優先する。指定数に足りない場合は同じ未着手主論点の別問題も選ぶが、同題の重複や既習論点での補充はしない。10問・30問を用意できない場合は開始できない。

## 学習状況

| 状態 | 判定 |
| --- | --- |
| 未着手 | 主論点への回答実績がない |
| 要復習 | 主論点の直近の回答が誤答、わからない、または確信のない正解 |
| 確認中 | 直近は確信正解だが、定着候補の条件は未達 |
| 定着候補 | 最後の誤答・迷いより後に、異なる問題群・内容で別のUTC日付に検証済み教材を確信正解 |

同じ問題の反復や再録問題では定着候補にしない。誤答・迷いが再発すると候補を取り消し、それ以降の確信正解で再確認する。「定着候補」は習得の保証ではなく、収録教材から得られる証拠を表す。

分野別内訳と主論点総数は、現在出題対象となる教材の主論点から集計する。論点数と、同題重複を除いた出題可能な問題数は別の数字。どちらも本試験全体の網羅率や予想得点を表さない。
