# 初期教材

2025年春期の高度共通午前Ⅰ（A-1相当）30問とNW午前Ⅱ（A-2相当）25問。
`2025-spring.json` は出典・表示領域・公式正答・独自解説を保持する。

原本PDFと問題画像は `npm run setup:materials` で `data/assets/2025-spring/` に準備する。
準備時に公式解答PDFを解析して55問の正答を照合する。
原本の図表を保持し、問題部分を切り抜く。問題文は改変しない。
画像と併せてページ番号・原問番号・原本へのリンクを表示する。

IPA公式過去問の著作権はIPAに帰属し、本プロジェクトのMITライセンスの対象外。
出典・改変表示は [IPA FAQ](https://www.ipa.go.jp/shiken/faq.html) に従う。
解説は本アプリ独自の教材であり、IPA公式解説ではない。
AI生成問題や独自の正答率を、本試験の出題・成績と同一とは扱わない。

現時点では2025年春期のみで、未着手模試専用の教材は未追加。
本番形式でも既出問題が含まれる場合があるため、初見評価とは区別する。

## 多年度の追加教材

`archive.json` に2016～2025年度の追加740問を保持する。基本教材と合わせ、A-1は570問、A-2は225問、計795問・28回分。追加分は公式正答を先行収録し、詳細解説・分野分類の未追加を明示する。年度をまたぐ再出題の重複整理は未完了。

`collect-archive.py` は公式の年度別ページからPDFを取得し、番号の画像検出とOCRで1～最終問の順序を検証する。OCRが不確かな場合は冊子を保留する。目視確認した例外は `verified-overrides.json` にPDFハッシュ付きで保持する。取得結果と原本のハッシュは `data/assets/archive/collection-report.json` に保存する。
