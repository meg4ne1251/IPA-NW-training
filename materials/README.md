# 初期教材

2026-10-24に目的別モード向けの独自補強42問を追加しました。現在の合計はA-1が738問、A-2が255問、計993問です。追加分の範囲・確認記録は [focused-supplement.md](focused-supplement.md) を参照してください。起動時に履歴を保持したまま登録します。

2025年春期の高度共通午前Ⅰ（A-1相当）30問とNW午前Ⅱ（A-2相当）25問。
`2025-spring.json` は出典・表示領域・公式正答・独自解説を保持する。

原本PDFと問題画像は `npm run setup:materials` で `data/assets/2025-spring/` に準備する。
準備時に公式解答PDFを解析して55問の正答を照合する。
原本の図表を保持し、問題部分を切り抜く。問題文は改変しない。
画像と併せてページ番号・原問番号・原本へのリンクを表示する。

IPA公式過去問の著作権はIPAに帰属し、本プロジェクトのMITライセンスの対象外。
出典・改変表示は [IPA FAQ](https://www.ipa.go.jp/shiken/faq.html) に従う。
解説は本アプリ独自の教材であり、IPA公式解説ではない。
AI生成問題や独自の正答率を、本試験の出題・成績と同一とは扱わない。

未着手模試専用の教材は未追加。
本番形式でも既出問題が含まれる場合があるため、初見評価とは区別する。

## 多年度の追加教材

`archive.json` に2016～2025年度の追加740問を保持する。基本教材と合わせ、A-1は570問、A-2は225問、計795問・28回分。追加分は公式正答を先行収録した原記録を保持する。2022～2025年度の追加解説285問は`official-explanations.json`から読出し時に反映し、残る2016～2021年度455問は詳細解説未追加と表示する。分野分類は`learning-priorities.json`から反映する。年度をまたぐ同題・類題は出題履歴に基づく問題群で重複を抑える。

`collect-archive.py` は公式の年度別ページからPDFを取得し、番号の画像検出とOCRで1～最終問の順序を検証する。OCRが不確かな場合は冊子を保留する。目視確認した例外は `verified-overrides.json` にPDFハッシュ付きで保持する。取得結果と原本のハッシュは `data/assets/archive/collection-report.json` に保存する。

## A-1の分野別補強

`a1-supplement.json` は24分野120問のAI作成教材。全問に分野・論点タグ、四肢択一、正答理由、四つの選択肢の説明、一次資料への参照、AIによる確認記録を保持する。画像やPDFの準備は不要で、起動時に既存DBへ追加登録される。

過去問と合わせてA-1は690問、A-2は225問、合計915問。人による監修や、試験範囲全体の網羅を意味しない。範囲と確認手順は [a1-supplement.md](a1-supplement.md) を参照。

## 分析に基づく出題メタデータ

`learning-priorities.json` は過去問795問の分類・論点・同題／類題の問題群・確認できた出題回数を保持します。調査根拠は `docs/research/` に保存しています。出題回数は過年度の観測値で、将来の出題確率ではありません。問題文・選択肢・正答は変更しません。既存DBを読み出す際に適用するため、再収集や学習履歴の書き換えは不要です。

短期集中テストでは、分野の配分、未着手の多さ、復習時期、解説の有無と観測された出題回数を考慮します。詳細解説が未追加の原本も候補に含み、その表示は保持します。

## 公式過去問の追加解説

`official-explanations.json`に2022～2025年度の285問の独自解説を収録しています。2026年10月20日には2022～2023年度の全170問（解説本文・選択肢説明で80,652字）を追加しました。全問に正答理由、全選択肢の説明、関連知識を付け、計算問題には途中式・検算を記載しています。2025年春期の既存55問と合わせ、直近4年度の340問は全問解説付きです。2016～2021年度の455問は未追加です。既存の学習履歴にも読出し時に反映し、回答記録は保持します。AI作成で、人による監修ではありません。[対象・確認方法・規格上の注意点](official-explanations.md)を参照してください。
