### 2024年午後Ⅱ問2・設問5の扱い

[IPAの公表](https://www.ipa.go.jp/news/2024/shiken_20240607.html)では、問題不備のため設問5 (1)～(3)は成立せず、本試験では問2を選択した受験者全員を当該設問について正解として扱っています。更新済みの問題冊子・解答例にも不成立の記載があります。本アプリではこの3設問を回答・自己評価の対象から除外し、演習開始時から出典付きの注意事項を表示します。原本画像・PDFの当該設問は改変していません。

回答欄の番号と明記された字数制限を設問ページと照合しました。公式解答例は表示上の空白を整理し、列挙欄は一つにまとめています。「又は」「複数の解答例」「解答の要点」はその性質を残して表示します。要点や複数候補の表示全体が設問の字数を超える場合もあるため、入力の文字数と公式例の長さを機械的に照合しません。改行を除いたUnicodeコードポイントで入力字数を数え、超過は注意表示にとどめます。

問題文と図表は原本のページ全体を表示します。Web画面のタイトル・検索用タグ・復習ヒントはアプリ側の学習用メタデータであり、IPA公式の解説や採点基準ではありません。第三者の解説は収録していません。学習のヒントと別にIPA公式採点講評PDFへのリンクを表示します。

## 再生成

通常利用では素材の取得作業は不要です。教材画像を再生成する場合だけ、PyMuPDFを利用できるPython環境で実行します。

```bash
.venv/bin/python scripts/setup-written-materials.py
npm run build
```

存在するPDFを優先し、未取得のものだけ公式からダウンロードします。保存済みのハッシュと一致しない原本は処理を中断します。教材JSON（`written-YYYY.json`）とマニフェストを年度ごとに照合して、各年度のディレクトリへ生成します。年度を追加する際は、原本を確認して教材JSON・出典マニフェスト・サーバーの読込年度を更新し、設問の全欄対応と字数を確認してください。

公式問題・図表・公式解答例・採点講評の著作権はIPAに帰属し、プロジェクトのMITライセンス対象外です。
