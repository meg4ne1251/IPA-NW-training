# IPA NW Training

2026年度ネットワークスペシャリスト試験対策のための、非公式Webアプリ開発プロジェクトです。
問題生成 → 演習 → 採点・解説 → 苦手分野の復習、という学習サイクルを目指します。

## 開発環境

Node.js 24 LTS と npm、Git を使用します。nvm を使う場合は `nvm install && nvm use`。

```bash
npm ci
npm run dev
```

表示されたローカルURL（通常 http://127.0.0.1:5173）を開いてください。
初期版にDB・外部API・環境変数は不要です。

```bash
npm test           # 出題・採点ロジックのテスト
npm run typecheck  # TypeScript型検査
npm run build      # 型検査と本番ビルド（dist/）
npm run preview    # ビルド後のローカル確認
```

## 現在できること

- 公式情報に基づいた2026年度の科目構成の表示
- オリジナル3問の順序を変えたサンプル演習
- 四肢択一の解答、採点、解説、再演習
- GitHub Actions によるテスト・ビルド

本番形式の問題数・時間制限・科目選択、記述式、AIによる新規問題生成、履歴保存は未実装です。
現在の「生成」は既存問題のランダムな組み合わせであり、新しい問題文の生成ではありません。

## 構成

- `src/domain/`: 試験定義・問題・出題と採点のロジック
- `src/main.tsx`: 初期画面とサンプル演習
- `docs/exam-2026.md`: 公式仕様と確認元
- `docs/product.md`: 要件・開発ロードマップ
- `docs/architecture.md`: 技術選定と拡張方針
- `CONTRIBUTING.md`: 開発手順

## 教材・ライセンス

IPAの公式サービスではなく、合格や本試験と同じ採点を保証しません。
収録問題は独自教材です。IPA過去問や第三者教材を追加する前に利用条件を確認してください。
