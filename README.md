# IPA NW Training

ネットワークスペシャリストの科目A-1を優先する、個人用の過去問演習アプリです。
過去問を解く → 結果を保存 → この環境のAIが分析・次セットを作成 → 取り込んで再演習、というサイクルを使います。

## Dockerで起動する（推奨）

Docker EngineとDocker Composeを使います。ホスト側でNode.jsやnpmを実行する必要はありません。

```bash
docker compose up -d --build
```

同じサーバーなら http://127.0.0.1:3001 、別の端末なら `http://サーバーのIP:3001` を開きます。全インターフェースの3001番ポートで公開します。認証はなく、自宅の信頼できるネットワークでの利用を想定しています。

ターミナルを閉じても稼働します。`restart: unless-stopped` により異常終了時とDocker起動時に再起動します。OS再起動後の自動起動にはDocker自体の自動起動も必要です（systemd環境では `sudo systemctl enable --now docker`）。手動で停止したコンテナは自動起動しないため、再開時は `docker compose up -d` を実行します。

既存の `./data` をそのままコンテナに接続するため、教材と学習履歴を引き継ぎ、コンテナを作り直しても保持します。別環境では教材を含む `data/` もコピーしてください。実行ユーザーは既定1000:1000です。所有者が異なる場合は `TRAINING_UID=$(id -u) TRAINING_GID=$(id -g) docker compose up -d --build` を使います。

```bash
docker compose ps                    # 状態確認
docker compose logs --tail=50 -f     # ログ（Ctrl+Cでログ表示だけ終了）
docker compose restart              # 再起動
docker compose down                 # 停止・コンテナ削除（dataは保持）
docker compose up -d --build         # コード更新後の再ビルド・起動
```

公開ポートを変える例：`TRAINING_PORT=8080 docker compose up -d` → `http://サーバーのIP:8080`。永続設定は `.env` に `TRAINING_PORT=8080` と記述できます（Composeが読み込みます）。

CLIの例：`docker compose exec training node server/cli.ts status`。従来の `npm start` と同じポートで同時起動しないでください。

## この環境で学習する

教材は準備済みです。Node.js 24以降で起動します。

```bash
npm ci
npm run build
npm start
```

http://127.0.0.1:3001 を開き、「A-1の診断を始める」または「10問を解く」を選びます。
同じ環境で `npm start` が既に動いている場合は、その画面を利用してください。

- 科目A-1/A-2、年度・期を選択できます。30問は1セットの大きさで、収録数の上限ではありません。
- A-1の「分野別の細かな補強」では、24分野120問の解説付き独自問題を、分野・論点で絞って解けます。
- 解答と自信度を選んで「この回答を確定する」を押すと、その1問の正誤・解説を表示します。確定後の解答・自信度は固定されます。
- 自信度「わからない」は選択肢なしでも確定できます。
- 10問・30問は保存上のセット単位です。全問の確定後は自動で完了し、「次の問題を続ける」で学習を続けられます。
- 診断・本番形式はA-1が30問50分、A-2が25問40分。こちらも1問ずつ解説を表示します。既出問題を含む場合があります。
- 回答・自信度・見直し・途中位置は、この環境のSQLiteへ保存されます。
- 再読込や再起動後も途中から再開でき、確定済みの正誤・解説も保持します。途中の採点結果も履歴・AI出力に反映します。
- 「セットを終了して結果を見る」または時間切れでは、未確定の回答もまとめて採点し、未回答は不正解として記録します。
- 保存に失敗した場合は未保存と表示し、ブラウザーに一時退避した回答から再試行できます。

Cloudflare Tunnelなど通信に遅延のある環境でも、解答・自信度・見直しの選択と問題移動はすぐ画面に反映します。保存中も次の操作ができ、連続操作は最新の内容をまとめて順番にサーバーへ保存します。「保存しています…」の間は保存完了前です。回答確定・セット提出は最新の回答の保存と採点を1回の通信で行います（実行中の保存があれば、その完了を待ちます）。次の問題画像も先読みします。

これはオンラインでの操作感を改善する変更です。保存先は引き続きサーバーのSQLiteで、通信失敗時は未保存を表示して手動で再試行します。オフライン学習・復旧後の自動マージは行いません。

履歴は `data/training.sqlite`、教材画像と原本は `data/assets/` に保存します。
`data/` はGit管理外です。`dist/` を更新しても学習データは保持します。

## 教材

2016～2025年度の高度共通午前Ⅰ（A-1相当）とNW午前Ⅱ（A-2相当）を収録しています。
各問題で原本の問題部分・図表を表示し、IPA公式解答と照合して採点します。
同じ回の共通午前Ⅰを試験区分ごとに重複収録していません。年度をまたぐ同題・類題は、出題履歴に基づく問題群で重複を抑えます。

2025年春期55問の既存解説に加え、2022～2025年度の285問へ詳しい独自解説を収録しています。2026年10月20日に2022～2023年度の全170問（約8.1万字）を追加し、2022～2025年度の収録済み公式過去問340問は全問に解説があります。追加分には正答理由、全選択肢の説明、途中式・検算、関連知識や誤りやすい点を含み、既存の履歴でも再読込すると読めます。残りの2016～2021年度455問は詳細解説未追加と表示します。古い法令・規格等は出題当時の前提に注意してください。[追加解説の範囲と確認記録](materials/official-explanations.md)を参照してください。
未着手の模試専用教材の確保、範囲全体の習得判定は今後の課題です。

これに加えて、A-1の基礎理論、アルゴリズム、CPU・OS、DB、ネットワーク、セキュリティ、開発、管理、戦略、会計、法務などを補強する120問を収録しています。A-1は過去問570問＋補強120問＝690問、A-2は225問、合計915問です。
補強問題はAI作成で、資料照合・計算や操作手順の検算を行い、全選択肢の説明と確認記録を付けています。人による監修ではありません。詳細は [補強教材の範囲と確認方法](materials/a1-supplement.md) を参照してください。

「分野別の細かな補強」で全分野または分野・論点を選び、10問・30問で始めます。収録数が少ない範囲はその件数で始まり、結果画面から同じ範囲で続けられます。通常の混合演習ではAI問題は20%以内、補強専用演習では補強問題のみを出題します。診断・本番形式は公式過去問を使います。
教材は起動時に追加登録されます。アプリを更新して再起動しても、既存の解答履歴は保持します。

別の環境で教材を再準備する場合：

```bash
python3 -m venv .venv
.venv/bin/pip install -r scripts/requirements-pdf.txt
npm run setup:materials
.venv/bin/python scripts/collect-archive.py
```

多年度収集には、IPA公式PDFとTesseract公式言語データのダウンロードが必要です。
問題番号の画像検出とOCRを使い、公式解答との全問対応を確認できない冊子は保留します。
目視確認が必要だった例外は、PDFのハッシュとともに `materials/verified-overrides.json` へ記録しています。
`data/assets/archive/collection-report.json` で取得結果を確認できます。

## 短期集中テスト

「今日の学習」でA-1またはA-2を選び、「短期集中で知識を増やす」の **短期集中テストを10問** または **30問** を押します。年度指定に関係なく全教材から選び、回答確定ごとに解説を確認できます。結果の「短期集中テストを続ける」で、同じ科目・問題数の演習を続けます。途中保存・再開も通常演習と同様です。

- 基本は未着手8割・復習2割。未着手が残っている間は、直前に解いた問題群を避けます。未着手の数や教材の残りに応じて調整し、足りない場合は少ない件数で始めます。
- A-1は技術17：管理5：戦略8、A-2はネットワーク15：セキュリティ6：その他4を目安に、収録範囲から幅広く選びます。A-1の短いセットでもセキュリティとネットワークを優先します。出題予測や本試験の再現ではありません。
- 誤答・迷いは6時間後、確信のある正解は72時間後を復習候補にします。新規問題を一巡した場合は再確認も出題します。
- 過年度の出題履歴に基づいて同題・類題をまとめ、1セットに同じ問題群を重複させません。頻出の問題群と、解説のある教材を優先します。AI作成問題は依頼した問題数の2割以内です。
- ホーム画面に「未着手」「復習の時期」の問題群数を表示します。問題群は同題・類題をまとめた単位であり、試験範囲の習得率ではありません。

[過去問分析](docs/research/nw-a1-a2-analysis-2026-10-18.md)をもとに、公式過去問795問の分類・論点と664の問題群を出題に反映しています。通常演習にも分類と重複抑制を反映します。既存の解答・教材の原本・セッションのスナップショットは保持し、履歴の分析時に現在の分類・問題群へ対応させます。

短期集中テストは既存の補強120問も使用します。公式過去問の追加解説285問は出題時の解説有無の評価にも反映します。2016～2021年度の455問は、正答のみで詳細解説が未追加である旨を表示します。

分析から出題用メタデータを作るスクリプトは `scripts/build-learning-priorities.py`、生成済みデータは `materials/learning-priorities.json` です。通常の起動では生成済みデータを使用します。再生成には保存済みの調査JSON・CSVを使い、論点名は調査時の一時HTMLキャッシュがあれば取得し、なければ細分類を使用します。

## AIに次セットを作ってもらう

1. 1問以上の回答を確定し、「学習画面へ」から「AIとの受け渡し」で対象科目の結果を出力する。途中の演習も分析できます。
2. 表示された `data/exports/<依頼ID>/learning-context.json` を読むよう、この環境のAIに依頼する。
3. AIに、履歴・問題画像から弱点を分析し、`nextSetTemplate` の形式で次セットを作ってもらう。
4. `next-set.json` を画面で取り込む。検証済みの既存問題から次の演習を始められる。
5. AI新規問題は未検証で保管する。根拠・正答の一意性・全選択肢の説明・計算を確認してから検証記録を付ける。

AIは常駐しません。分析と生成はユーザーの依頼で行います。外部AI APIやAPIキーは不要です。

CLIでも同じ入出力を使えます。

```bash
npm run training -- export A-1
npm run training -- import data/imports/<依頼ID>/next-set.json
npm run training -- status
```

新規問題は、エクスポートの `availableQuestions` にある問題形式に従い、`origin: "ai"`、`version: 1`、`review.status: "draft"`、新しいIDと4件の `choiceExplanations` を指定します。
`selected` には既存問題と新規問題のID・版・出題理由を入れます。新規類題は1回6問まで、セットは30問までです。
取り込みで `verified` と自己申告しても、AI新規問題は必ず未検証に戻します。

内容を実際に確認した後に、確認方法・根拠URL・確認者を記録します。

```bash
npm run training -- verify <問題ID> '正答と全選択肢を根拠資料で照合し、計算も別手順で検算した' https://根拠資料のURL 確認者名
```

既に取り込んだセットの出題可能件数にも反映されます。セットを開始する前に確認してください。
出力後に別の回答を確定したり演習を提出した場合は、最新の結果から作り直します。依頼IDの再取り込みでは重複登録しません。

## バックアップと復元

画面のバックアップボタン、または次のコマンドで、整合性のあるDBコピーとJSONを保存します。
履歴のあるサーバーの起動時と、連続稼働中は24時間ごとにも保存します。

```bash
npm run training -- backup
```

`data/backups/` のSQLiteコピーと、`data/assets/` を一緒に退避してください。JSONには教材・履歴・生成依頼・取り込み記録が含まれます。
環境内のコピーだけでは環境自体の消失には備えられないため、必要に応じて環境外にも保存します。

復元する場合はサーバーを止め、別の空ディレクトリにバックアップSQLiteを `training.sqlite` という名前で置き、同じ場所に `assets/` をコピーします。
`TRAINING_DATA_DIR=/そのディレクトリ npm start` で復元内容を開けます。稼働中のDBやWALファイルを上書きしないでください。

## 開発・確認

```bash
npm run dev        # API :3001 と Vite :5173 を起動
npm test           # 出題・保存・採点・AI連携のテスト
npm run typecheck
npm run build
```

開発画面は http://127.0.0.1:5173 。学習用の本番ビルドを利用するときは開発サーバーを止めてから `npm start` します。
ポートは `PORT`、保存先は `TRAINING_DATA_DIR` で変更可能です。開発用ViteのAPI転送先は既定の3001です。

ブラウザーテストは専用の一時DBを使い、実際の学習履歴を変更しません。

```bash
npx playwright install --with-deps chromium
npm run build
npm run test:e2e
```

## 構成・仕様

- `src/domain/`: 試験定義、入力検証、出題・採点・弱点集計
- `src/main.tsx`: 演習、保存・再開、結果、履歴、AIファイル入出力
- `server/`: SQLite保存、ローカルAPI、CLI
- `materials/`: 公式教材の出典・正答・画像位置、独自解説
- `scripts/`: 教材準備、開発用起動、ブラウザーテスト用起動
- [基本仕様](docs/adaptive-learning.md)、[開発計画](docs/product.md)、[技術構成](docs/architecture.md)、[公式試験仕様](docs/exam-2026.md)
