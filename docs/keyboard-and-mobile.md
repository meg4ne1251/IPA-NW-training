# 端末とキーボード操作

スマートフォンではカードを縦に配置し、自信度・選択肢を2列で表示します。問題番号とボタンは44px以上のタッチ領域を確保しています。問題画像はタップで拡大できます。

PCでは次のキーで操作できます。

- h / l：前の問題 / 次の問題
- j / k：次 / 前の入力・ボタン・リンクへフォーカス
- Enter：フォーカスしたボタン・リンクの実行
- Space：ラジオ・チェックボックスの選択
- f：全ボタン・リンク・入力欄に2文字の操作キーを表示。表示されたキーを順に入力するとクリックと同じ処理を実行します。文字入力欄・選択欄はフォーカスします。
- Esc：操作キー表示を解除

操作キーはホーム段を優先して割り当てます。無効なボタンは対象外です。文字入力中・IME変換中・修飾キー併用時は通常の入力を優先します。提出操作は画面操作と同じ確認手順が必要です。

自信度「わからない」は `confidence: "unknown"` として保存します。未入力の `null`、推測の `guess` と区別し、途中保存、再開、提出結果、JSON出力に保持します。AIへの指示には、正誤にかかわらず基礎から学習する分野・概念の判定に利用するよう明記しています。
