# A-1の履歴に応じたカリキュラム

未着手論点の演習を終えた後は、ホームの「解答結果からのおすすめ演習」を使う。新しい`a1-curriculum`モードは全年度・検証済みのA-1教材から10問または30問を選び、回答確定ごとの解説・保存・再開・同じ件数での継続に対応する。現在の履歴から毎回選び直すため、セットを事前に大量作成しない。

## 取り組み方

1. まず10問を解く。誤答・わからないでは、解説の理由や計算過程を自分で説明できるよう確認する。
2. 続けると別問題を使って弱点を補強する。分からない段階では無理に30問へ増やす必要はない。
3. 確信正解した論点は同日中の確認から外し、別のUTC日付かつ6時間以上後に別問題で確かめる。
4. 最後の誤答・迷いの後、異なる問題群・内容で別日に確信正解した論点を定着候補とする。定着候補は72時間後から再確認する。

確信がない正解も復習対象。「要復習」は直近の証拠による確認対象であり、分野全体の能力や試験得点の断定ではない。本番形式の練習は従来の別モードで行う。

## 選抜

基本目安は弱点60%・別日確認30%・未着手10%。10問なら6・3・1、30問なら18・9・3。未着手が少ない、当日確信正解したばかりなどの場合は候補のある段階へ再配分する。画面に次の10問・30問の実際の構成を表示する。AI問題の割合はこの補強専用モードでは制限しない。

- 分類と状態は`a1Coverage`の主論点を共用する。大分類が同じという理由で無関係な問題を弱点の類題にはしない。
- 未回答の別問題を優先し、同じ論点を繰り返す前に異なる論点を広げる。各段階では分野の偏りを抑え、誤答・わからない、全選択肢の説明がある問題、古い確認順で優先する。
- 弱点の別問題はすぐ利用できる。既出を使うのは未回答の候補が不足した場合だけで、論点の直近回答から誤答等は6時間、確信正解は72時間以上空ける。理由と既出問題の件数を表示する。同じ問題で正解し直すだけでは定着候補にならない。
- ID・版違い・問題群・同内容をセット内で重複させない。未検証・出題終了・保留問題と保留問題群は除外する。
- 選択肢も自信度もない一括提出は着手や弱点に数えない。選択肢なしの「わからない」は着手・弱点に数える。
- 指定数を用意できなければ開始を無効にし、APIでも拒否する。最近確信正解した問題で穴埋めしない。

ホームに優先論点と別問題不足の論点を表示する。別問題不足は追加教材を判断するための指標で、既出問題の再回答を新規教材と数えない。個人の分析記録は`data/analysis/`に保存し、Gitへ含めない。

## 既存機能との関係

未着手専用・復習専用・通常・短期集中・A-2の出題方式はそのまま使える。おすすめ演習は新しい選択肢として追加し、既存のセッションを変換しない。教材登録は新IDの追加のみ。SQLiteのスキーマ変更や履歴の書換えは行わない。

自動検証では、配分、未着手不足時の再配分、日付と時間の境界、確信正解後の抑制、同題除外、教材の検算、API保存・再開・再起動を確認する。ブラウザー検証は実データから分離した一時DBで行う。
