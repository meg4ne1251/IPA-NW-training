# 作るものと開発計画

## 目的

ネットワークスペシャリスト試験の知識と、設計・障害解析を文章で説明する力を鍛える。
2026年度のCBT方式に合わせ、画面上で問題を読み、選択・文字入力で解答する。

## 学習の流れ

1. 科目・分野・問題数・難易度を選ぶ。
2. 問題バンクから練習セット、または本番形式の模試を生成する。
3. 解答し、正誤・解説・参考資料を確認する。
4. 記録された苦手分野や誤答を復習する。

## 段階的な実装

- [x] 初期環境、公式仕様整理、サンプル四肢択一、CI
- [ ] 問題スキーマ（科目、分野、難易度、出典、レビュー状態）と入力検証
- [ ] A-1/A-2の問題追加、分野別出題、本番問題数を満たすバンク
- [ ] CBT練習：タイマー、見直しフラグ、未回答一覧、時間切れ提出、A-1免除
- [ ] B-1/B-2：事例本文・構成図・小問・字数制限・大問選択
- [ ] 記述式の模範解答と観点別自己採点（公式採点とは区別）
- [ ] 学習履歴の端末保存、分野別成績、誤答の再出題
- [ ] 必要に応じてサーバー・DB・認証を導入し端末間同期
- [ ] 任意のAI問題生成：サーバー側呼出し、予算制限、構造検証、人のレビュー

## 受入条件

練習モードと本番模試を明示的に分ける。問題不足を重複出題で隠さない。
選択式は未回答を正答にせず、採点後に根拠を表示する。
記述式は公式採点の再現をうたわない。生成問題にはレビュー状態を保持する。
小さい画面、キーボード操作、再読込、保存失敗も各機能の実装時に確認する。
ログイン不要の練習を先に完成させる。
