# 作るものと開発計画

## 目的と優先順位

2026年度NW試験の科目A-1/A-2を対象に、過去問の演習結果から弱点を見つけ、復習とAI生成問題で理解を確かめる個人用学習アプリを作る。特にA-1を優先する。

学習条件は1日2時間、受験日は2026年10月26日。まず7日間・計14時間の学習サイクルを成立させ、10月24・25日は予備日とする。A-1に約80%、A-2に約20%を配分する案から始め、初回診断で調整する。満点を目指すが、到達度は未着手の過去問で判断する。

開発環境をそのまま個人用の本番環境として利用する。既存のReact画面を活かし、同じ環境に履歴を保存してAIが読み込めるようにする。

詳細は [適応学習の基本仕様](adaptive-learning.md)、[技術構成](architecture.md)、[公式確認事項](exam-2026.md) を参照。

## 最優先の学習サイクル

1. A-1の過去問30問を解き、正誤・自信度・所要時間を記録する。
2. 解説を確認し、誤答、迷った正解、未学習分野を集計する。
3. 集計と関連する解答履歴をファイルへ出力する。
4. AIが結果を読み、次の問題セットと少数の類題を作成する。
5. 問題の形式・正答・根拠を検証し、出題可能なセットを取り込む。
6. 再演習し、翌日・3日後にも理解が維持されているかを確認する。

初期版ではAIに分析・作成を依頼する操作をユーザーが行う。アプリ単体での完全自動生成は後続とし、外部AI APIの導入を学習開始の条件にしない。

## 受入条件

- 解答・中断位置が再読込やサーバー再起動後も復元される。保存失敗を明示する。
- 記録された問題版の正答と照合して採点する。未回答は不正解とし、二重提出で履歴を重複させない。
- 出典と、過去問・改変・AI独自生成の区別を表示する。
- AI向けに結果を出力でき、取り込んだセットを次の演習として解ける。
- 未検証・疑義ありの教材を通常出題から除外する。AI生成失敗時も過去問演習を続けられる。
- 弱点反復と別に、未着手分野と未着手問題の成績を確認できる。
- 練習と本番形式を分け、問題不足を重複出題で隠さない。
- 小さい画面、キーボード操作、保存・復元を各機能の実装時に確認する。
- 同じ環境でアプリを更新しても、教材・履歴・バックアップを消さない。

初期の学習サイクルは実装済み。追加分の教材分類・解説と、未着手模試による高得点の確認は未完了。1週間の満点到達を保証するものではない。
