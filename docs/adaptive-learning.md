# A-1優先・過去問とAIによる適応学習の基本仕様案

作成日：2026-10-16。対象年度：2026。学習条件：1日2時間、受験日10月26日。
「1日にじかん」という回答は1日2時間と解釈した。
比率・問題数・到達目安は本プロジェクトの提案値であり、公式基準や達成保証ではない。

## 実装状況（2026-10-16）

初期サイクル、保存・再開、タイマー、年度選択、AI用JSONの入出力を実装。ユーザーの追加希望により収録目安を拡大し、2016～2025年度のA-1 570問・A-2 225問、合計795問を収録した。30問は1セットの単位であり、収録数・演習回数の上限ではない。詳細解説・分類は2025年春期55問が対応し、追加740問は公式正答を先行収録。以下の詳細仕様には未完了の項目も含む。実装状況は [開発計画](product.md) を参照。

## 1. 目的と範囲

2026-10-18追記：A-1に24分野120問のAI作成補強教材を追加。A-1計690問、A-2計225問、総計915問。分野・論点を指定する補強専用演習では、確認済みの補強問題だけを出題する。通常の混合演習はAI問題20%以内を維持し、診断・本番形式は公式過去問を使う。全分野の演習では未着手の問題を分野ごとに分散させ、同じ範囲での継続・再開にも対応する。確認内容は [補強教材の記録](../materials/a1-supplement.md) を参照。

主目標はA-1で満点に近い成績を目指し、初めて見る類題にも対応できる知識を身につけること。A-2も継続し、科目ごとに成績を分ける。まず7日間・14時間、A-1に約80%、A-2に約20%を配分する。

初期対象は個人1人、既存環境、ブラウザーでの四肢択一。B科目、一般公開サービス、ログイン、他端末同期、AI APIの自動呼出しは後続とする。

A-1は高度試験の共通知識を問うため、ネットワークだけに絞らない。試験要綱の中分類を基準に、基礎理論、アルゴリズム、コンピュータ、ソフトウェア、DB、ネットワーク、セキュリティ、開発、マネジメント、戦略、企業活動・法務まで管理する。A-2はNWの対象分野とレベルを別に設定する。

正式な中分類IDと「CIDR」「待ち行列」「損益分岐点」などの概念タグを分ける。同じ概念でも科目間の成績を自動で同一視しない。

## 2. 学習サイクル

1. **診断**：A-1過去問1回分30問を50分以内で解き、自信度も選ぶ。
2. **記録**：選択肢、正誤、未回答、時間、自信度、問題版を保存する。
3. **理解**：正答の理由と各誤選択肢の誤りを確認し、必要に応じて誤答理由を付ける。
4. **分析**：30問ごと、または学習終了時に、AI向けの結果と次セットの依頼を出力する。
5. **作成**：AIが弱点を分析し、既存問題の選抜と少数の新規類題を作る。
6. **検証**：構造・正答・根拠を確認したものだけを出題可能にする。
7. **再演習**：短いセットを解き、翌日・3日後の再確認へつなぐ。

30問は分析タイミングの初期値。未完了でも保存し、短時間の学習を妨げない。分析には過去の履歴も使い、直前の30問だけで弱点を決めない。

例：稼働率を誤答したら、原問の再確認に加えて直列・並列の条件を変えた類題を出す。解説直後の正解は理解確認、翌日の別問題での正解は定着確認として扱う。

## 3. 問題バンク

- A-1は旧午前Ⅰの公式過去問を主教材にする。同一回の共通問題を試験区分ごとに重複登録しない。
- A-2はNWの旧午前Ⅱを主教材にする。他区分の問題はNWの範囲・レベルを照合して補助教材とする。
- 最初にA-1の30問を取り込み、診断可能にする。続けてA-2の25問を追加する。
- 初期の拡充目安はA-1合計240～300問、A-2合計100～125問だったが、追加希望により収録を拡大した。全問を解くノルマにはしない。
- このうちA-1は模試用に3セット90問、A-2は1セット25問を確保する。練習・解説・AI生成の入力に使わない。
- 同一・ほぼ同じ問題と既知の派生問題にはグループIDを付け、模試用にはグループ単位で確保する。
- アプリ外で見たことがある問題はユーザーが申告し、未着手評価から外せるようにする。
- 古い法律・規格等は適用時点を保持し、現行範囲との不整合が解決できない問題は出題しない。

年度・期・試験区分・旧科目名・問番号・問題PDF URL・解答PDF URL・ページを保持する。公式PDFと照合し、図表、選択肢の順序、数式、正答の対応を確認する。正答キーは公式解答に従う。解説は別に作成・検証し、公式問題とAIの説明を区別する。

PDFの完全自動抽出は必須にしない。初期は問題部分の画像や該当PDFページを表示し、解答欄を紐付ける方式も認める。図表が必要な問題は表示を確認するまで出題しない。

IPA FAQに従って出典を表示し、改変は明記する。第三者サイトの解説を転載しない。過去問・第三者素材は独自教材のMITライセンスと分ける。

## 4. 演習機能

| モード | 動作 |
| --- | --- |
| 初回診断 | A-1過去問30問。1問の回答を確定するたびに正誤・解説を表示し、成績を保存 |
| 今日の演習 | 10問単位で中断できる。合計30問を目安に弱点・復習・未学習を組み合わせる |
| 苦手の復習 | 期限の来た問題、同じ概念の別問題、検証済みのAI類題 |
| 本番形式 | A-1は30問50分、A-2は25問40分。移動・見直し・時間切れ提出 |
| 履歴・分析 | 科目別成績、分野別件数、復習予定、未学習分野、AIへの出力 |

- 自信度は「確信あり／迷った／推測／わからない」。未入力も許容し、確信ありとして扱わない。
- 誤答理由は「知識不足／用語の混同／計算・手順／読み違い／時間不足／その他」。任意でメモを残せる。
- 練習・診断・本番形式・取り込みセットのすべてで、1問の回答を確定した直後にその問題の正誤・解説を表示する。他の未確定問題の正答は表示しない。
- 正答、理由、誤選択肢ごとの説明、覚える要点、根拠、問題の出自を表示する。
- 回答ごとに保存し、確定前の変更と採点済みの最終解答を区別する。確定後の解答・自信度は変更できない。途中の採点済み問題も履歴・AI出力に含め、セット完了時に二重計上しない。
- 正答率と併せて、初見正答率、迷った正解、推測正解、未回答を示す。
- 疑わしい問題を報告できる。疑義のある教材は出題停止し、弱点集計から一旦除外する。

回答時間は実際に取り組んだ時間を基本とし、練習の一時停止や非表示時間を区別する。本番形式は終了日時を保存し、再読込で時間を延ばさない。時間は判断の補助とし、離席だけで苦手認定しない。

## 5. 苦手判定と選抜

最初は説明できる規則で選抜する。習熟度をAIの印象だけで決めない。

| 状態 | 扱い |
| --- | --- |
| 自信があるのに不正解 | 最優先。選んだ誤選択肢から誤解を確認する |
| 不正解・未回答 | 弱点候補。理由を確認し、基礎説明と別問題を出す |
| 正解だが迷った・推測・自信度不明 | 不安定。習得済みにせず、後日別問題で再確認 |
| 正解だが時間がかかった | 計算・判断手順を確認。時間だけでは弱点確定にしない |
| 別日・異なる問題で確信を持って正解 | 定着候補。出題頻度を下げ、維持確認へ回す |
| 未着手・回答例が少ない | 未評価と表示。低い正答率と区別する |

分野ごとに初回成績と直近成績を分け、回答数と異なる問題の数を表示する。同じ問題の繰り返しでは異なる問題の数を増やさない。単一の誤答だけで分野全体を苦手と断定しない。

A-1の学習用30問セットの初期配分は以下。本番の分野別配分とは別であり、10問ごとの練習はこのセットを分割する。

| 枠 | 問題数 | 選択基準 |
| --- | --- | --- |
| 復習期限 | 8 | 翌日・3日後などの再確認 |
| 苦手補強 | 12 | 誤解、不正解、不安定な正解。同じ概念の別問題を優先 |
| 未学習の確認 | 6 | 未着手分野・学習例の少ない分野 |
| 得意分野の維持 | 4 | 定着候補から間隔を空けて確認 |

上から重複を除いて選ぶ。苦手補強の中にAI類題を初期値3～6問、上限6問まで含める。診断には含めない。A-2の学習用セットも同じ比率を目安に件数を調整し、両科目の問題を一つの成績に混ぜない。

枠の不足は同じ科目の検証済み過去問から未着手→復習→維持の順で補い、配分変更を記録する。模試用問題や未検証教材では補わない。件数そのものが不足する場合は短い練習として明示し、本番形式に必要な件数がなければ開始できない。

弱点内では繰り返す誤り・自信のある誤答を優先する。同程度なら実際に収録した過去問で出現する概念を優先し、集計対象年度と件数を表示する。頻出率を推測で作らない。難問だけに寄せず、誤答した前提知識まで戻る。

誤答は解説後の確認に加え、翌日・3日後・7日後を復習候補とする。受験後の日付になる場合は受験前に一度確認する。異なる日に異なる問題を確信ありで2回正解した概念を定着候補とするが、少数の正解から習得率100%とは表示しない。

## 6. AIとの受け渡し

初期版は、この作業環境でAIがファイルを読んで問題を作る方式。ユーザーは演習後に「結果を読んで次の問題セットを作成して」と依頼する。AIの常駐や、ブラウザー終了後の自動実行を前提にしない。

想定ファイルは以下。まだ実装済みのパス・コマンドではない。

```text
data/
  training.sqlite                    # 教材、履歴、セットの正本
  assets/                            # 図表・PDF
  exports/<request-id>/
    learning-context.json            # 集計と関連する履歴
    generation-request.json          # 科目、配分、制約、履歴の基準時点
  imports/<request-id>/
    next-set.json                    # 次セット、生成問題、検証根拠
  backups/                           # DBと必要な教材の世代バックアップ
```

エクスポートには科目、履歴の基準時点、分野別集計と件数、誤答・迷った問題の本文と選択肢、選んだ答え、正答、誤答理由、過去の復習成績、次回期限、未学習分野を含める。苦手概念の履歴を優先し、全履歴を無制限にプロンプトへ詰め込まない。

AIの出力には既存問題のIDと版、新規類題、出題理由、狙う誤解、解説、各選択肢の説明、根拠を必須とする。基礎確認、計算条件の変更、概念比較を中心に作成する。選択肢の並べ替えだけは新規問題として扱わない。

データにはスキーマ版、依頼ID、履歴の基準時点を持たせる。通常のAI入力に模試用問題を渡さない。AIはDBを直接書き換えず、検証付きインポート処理で教材とセットを反映する。

履歴保存・集計・エクスポート・取り込み後の採点はアプリが行い、AIの分析・作成はユーザーの依頼で実行する。将来自動化する場合も同じ入出力形式を使う。

## 7. AI教材の品質管理

教材状態は `draft`（未検証）→ `verified`（出題可能）とし、`disputed`（疑義）・`retired`（出題終了）も持つ。AIの自己申告だけで出題可能にしない。

取り込み時の最低条件：

1. 四つの異なる選択肢、正答ID、本文、分野、解説、根拠などの構造を検証する。
2. 正答が一意で、条件・単位・数値に矛盾がないことを確認する。計算は別の計算手順やスクリプトでも検算する。
3. 技術知識は公式文書・規格等と照合し、誤選択肢の説明も確認する。確認できなければ未検証に留める。
4. 重複、模試用問題との既知の派生関係、図表の欠落を確認する。
5. 検証方法・確認者・日時を記録する。構造検証と内容検証を分ける。

形式不備や未知のIDがあるセットは一括で取り込みを拒否し、理由を返す。内容検証が未完了の候補は未検証状態で保管できるが、出題には入れない。検証済み問題だけで構成したセットを別途確定する。依頼IDの再取り込みは二重登録しない。古い履歴を基準にしたセットは確認対象にし、学習状況を巻き戻さない。

生成・検証に失敗しても既存の過去問で続ける。教材修正は新しい版を作り、過去の教材と採点結果を保持する。疑義のある版は弱点集計から除外し、修正後の再集計を区別する。

## 8. 保存データ

| データ | 最低限の項目 |
| --- | --- |
| 問題と版 | ID、版、科目、分野、概念タグ、難易度、本文、図表、選択肢ID、正答ID、解説、出自、出典、原問ID、重複グループID、検証状態 |
| 出題セット | ID、モード、科目、問題IDと版・表示順、選択肢順、選抜理由、作成元、開始・終了日時、状態 |
| 解答履歴 | 解答ID、セットID、問題IDと版、最終選択肢IDまたは未回答、正誤、自信度、時間、誤答理由、提出日時 |
| 中断状態 | セットID、回答途中の内容、現在位置、見直しフラグ、保存日時、本番形式の終了予定日時 |
| 復習予定 | 科目、概念または問題、次回日時、異なる問題での直近成績、予定理由 |
| 生成・検証記録 | 依頼ID、履歴の基準時点、指示と制約、生成元と日時、検証結果、採用問題、保留理由 |

1問の採点とセットの提出はそれぞれ一つのトランザクションで確定し、通信再試行や二重クリックで履歴を増やさない。分野別成績は履歴から再計算可能にし、AIの要約を唯一の記録にしない。

## 9. 1日2時間・7日間の学習案

10月17～23日の7日間を基本枠とする。開始日が変われば相対日程として移動できる。10月24・25日は予備日とし、14時間の基本計画へ自動で上乗せしない。

| 日 | 120分の配分 | 確認すること |
| --- | --- | --- |
| 1 | A-1診断50分、解説40分、A-2短い診断20分、整理10分 | 基準となる成績、最優先の弱点 |
| 2 | 期限復習20分、弱点過去問30分、解説30分、AI類題15分、A-2を15分、整理10分 | 基礎知識と誤解の修正 |
| 3 | 2日目と同じ配分で、弱点と未学習分野を確認 | 前日の理解を保持しているか |
| 4 | 2日目と同じ配分で、復習と未学習の抜けを補強 | 同じ概念の別問題に対応できるか |
| 5 | 未着手A-1模試50分、解説35分、A-2を25分、整理10分 | 初見の正解数、残る取りこぼし |
| 6 | 別の未着手A-1模試50分、未着手A-2模試40分、解説30分 | 両科目の到達度、時間内完答 |
| 7 | 別の未着手A-1模試50分、要点・誤答復習40分、A-2復習20分、整理10分 | 最後まで残る誤解、計算手順、用語 |

AI類題15分には作成待ち・取り込みも含める。間に合わなければ検証済み過去問に置き換える。問題数ノルマより解説と後日の再確認を優先する。

到達目安はA-1の未着手模試3セットでそれぞれ29/30問以上、A-2の未着手模試で24/25問以上を目指す。独自の高得点目標であり、本試験の得点予測ではない。A-2の評価が1セットだけなら評価材料が少ないと表示する。繰り返し問題の正解率と混ぜず、時間内完答と自信度も併記する。

初回診断が低ければAI新規問題を減らし、基礎解説と過去問での範囲確認に時間を戻す。予備日は未解消の誤答・迷った正解を確認する。満点到達は初期知識と実測成績に左右され、1週間での保証はしない。

## 10. 最初の完成単位と受入確認

最初は「A-1の30問→保存→AI向け出力→次セットの検証・取り込み→再演習」の一巡を完成させる。その後、教材拡充・復習予定・分野別選抜・模試を追加する。正しい教材、履歴保存、すぐ学習できる状態を優先する。

- 回答・自信度・中断位置が再読込とサーバー再起動後も復元される。
- 保存失敗を表示し、再送でも解答を重複させない。
- 未回答を不正解とし、教材更新後も当時の版を参照できる。
- 自信のある誤答、迷った正解、未学習、繰り返し正解を規則どおり区別する。
- 問題不足を表示し、未検証・疑義あり・模試用問題を練習に混ぜない。
- 次セットの選抜理由と履歴の基準時点を説明できる。
- 出力→AI作成→検証・取り込み→演習を実データで一巡できる。
- 不正な取り込みは途中まで反映せず、再取り込みでも重複登録しない。
- バックアップから教材版・セット・履歴を復元し、続きから学習できる。
- 更新時にデータを保持し、直前の動作するアプリへ戻せる。

## 短期集中テスト（2026-10-18）

`practiceScope.collection = rapid-knowledge` の練習として永続化。既存の練習・年度別演習・補強専用演習と識別し、結果からの継続でも科目・問題数・範囲を保持する。`selectRapid` は未着手を中心に、6時間以上経った誤答・迷いを約2割、確信正解は72時間以上を復習候補とする。新規が不足すると残りに合わせて配分を調整する。新規が残る間は直前の既出群を除き、数合わせの重複を行わない。

A-1の分野重みは17/5/8、A-2は15/6/4。端数は最大剰余法で配り、候補のない分野は他分野から補う。セット内の分野・論点の偏り、過去の着手量、弱点、説明の有無、確認された再出題回数を順位付けに使う。AI上限は指定問数の20%。未検証と模試用の派生群を除外する。

`withLearningPriority` は過去問795問と履歴を、原本の正答や保存済みスナップショットを変更せず現在の分類・664群へ対応させる。通常演習でもこの分類と群を利用。解答前は論点名を含むlearningフィールドを返さず、従来どおりタグ・正答・解説を非公開にする。


## 2026-10-20 実装：概念別分析と同一問題を使わない復習

通常・補強・短期集中の新規練習では、履歴内のID・同一問題群・同一の本文と選択肢を除く。履歴にある問題を新しい版として再出題することもしない。診断・本番形式の原本セット、保存済み演習の再開・結果表示はこの除外の対象外。候補不足では短縮又は不足の通知を行う。

`reviewConcepts` で別の問題群を結び、直近の概念別解答から補強・復習を選ぶ。誤答・迷い・わからないは6時間、確信正解は72時間を復習目安とする。苦手補強はこの時期より前でも別問題を使う。短期集中では未着手の概念を優先し、残りが不足する場合に未着手の関連問題から補充する。AIの上限は従来どおり通常・短期集中で要求件数の2割、補強専用では全件。

分析は初回と直近の成績・自信度を分ける。正解でもunknownは基礎確認。最後の誤答・不安定な解答より後、UTCの別日・異なる問題群で確信正解を2回確認した概念だけを定着候補とする。習得率の推定や正答率だけの分野全体の断定はしない。

AI出力には分析・既出群・代替不足を追加。取り込み済みセットは開始時にも履歴を確認し、既出項目を概念が共通する検証済みの別問題へ置換する。検証済みの代替がなければその項目は出さず、出題可能件数を減らす。開始済みのスナップショットや解答履歴は変更しない。
