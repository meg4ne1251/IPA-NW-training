# 記述試験対策

## 使い方

`/` と `/written` が科目B記述対策の入口、`/choice` が従来の科目A選択式対策です。従来の `/#session/<ID>` ブックマークも選択式の演習として開きます。

1. 大問を1つ選びます。科目・キーワード・未着手／復習対象で絞り込めます。
2. 原本の問題文と図表を読み、設問に対応した欄に解答します。「設問のページへ」で設問がある原本ページに移動できます。
3. 記述欄には字数を表示します。明記された上限を超えると注意を表示しますが、考え直せるよう入力は継続できます。
4. 「公式解答例で答え合わせ」で回答を固定し、公式解答例・要点と比較します。未回答がある場合は画面内で確認します。
5. 全回答欄に「できた・一部できた・要復習」の自己評価を付け、メモを残して完了します。振り返り中も保存して後から再開できます。
6. 同じ大問を解き直すと新しい記録を作ります。過去の回答と振り返りは履歴から確認できます。同じ問題に未完了の記録があれば、その記録を再開します。

B-1は本来3大問から2大問を90分で解くため、1大問45分を練習の目安としています。B-2は2大問から1大問を120分です。本機能は大問単位の練習モードで、本番の選択・一括提出を再現する模試ではありません。「開始からの経過」は実時間で、画面を閉じている間も含みます。解答例を表示すると経過表示は止まります。時間切れによる自動終了はありません。

記述は同じ意味の表現が複数あるため、単語一致による自動採点を使いません。履歴は自己評価の件数で、本試験の得点や合否を表しません。トップの復習対象は各大問の直近の記録に「一部できた」又は「要復習」がある大問です。

## 保存と復旧

- SQLite `data/training.sqlite` の `written_sessions` に回答・問題のスナップショット・メモ・自己評価・閲覧ページ・時刻を保存します。科目Aのテーブルと学習判定には影響しません。
- 約650msの入力待ち後に自動保存し、通信を順番に送ります。保存中の編集は応答後に最新版を保存し、古い応答で新しい入力を消しません。
- 「保存して一覧へ」は未保存分を保存してから移動します。未保存状態でページを閉じる際はブラウザーの確認対象にします。
- 通信失敗時は未保存と明示し、再試行と回答JSONのダウンロードができます。ローカルストレージが使えるブラウザーでは未保存の下書きを退避し、同じ保存版なら再読込時に復元します。
- 別の画面で更新された場合はHTTP 409で停止し、サーバーを上書きしません。控えを保存してから最新の保存内容を読み込めます。回答JSONは手元で参照するための出力で、取り込み機能はありません。
- 通常のSQLiteバックアップとJSONバックアップに記述履歴も含みます。教材PDFと画像はDockerイメージに同梱され、記述対策には既存の`data/assets`の教材準備も外部APIキーも不要です。

記述演習のJSON出力は既存の科目A向けAI連携とは別形式です。学習履歴のバックアップは既存の `npm run training -- backup` 又は `docker compose exec training node server/cli.ts backup` を利用できます。

## 実装と確認

- `src/written-app.tsx`：記述対策の画面。
- `src/written-sync.ts`：順番に行う保存、退避、競合検出。
- `src/domain/written.ts`：記述演習の型と表示用定義。
- `server/written.ts`：教材、演習作成、保存、解答例の公開、自己評価の完了。
- `materials/written.md`：教材の出典と照合記録。
- `server/written.test.ts`：保存・再開・固定・検証・バックアップ。
- `e2e/written.spec.ts`：トップ切替、スマートフォン、回答から解き直しまで、通信失敗、別タブの競合。

解答例と学習ヒントは、回答を固定するまでは演習APIから返しません。原本は公開済みの公式資料であり、教材ファイルへの直接アクセスを禁止する機能ではありません。
