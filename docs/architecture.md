# 技術構成

## 現在の構成

React + TypeScript + Vite の画面と、Node.js標準HTTPサーバー、標準SQLite APIで構成する個人用アプリ。
Node.js 24以降を使用する。npm lockfileで依存を固定し、CIではテスト・型検査・本番ビルドを確認する。

```text
ブラウザー（React）
  → 同一オリジンのローカルAPI
    → data/training.sqlite
    → data/assets/（公式PDF、問題部分の画像）
    → JSON出力 → この環境のAIが次セット候補を作成
    ← 検証付き取り込み ← 候補JSON
```

正本は環境上のSQLite。ブラウザーのlocalStorageは未保存回答の一時退避だけに使う。
AIはユーザーの依頼でファイルを読み、候補を作る。AIの常駐・外部API呼出しは実装していない。
DBの変更はアプリと共通の保存・検証処理を通す。

## 処理の分離

- `src/domain/training.ts`：問題型、入力検証、習熟の状態に応じた選抜、履歴の集計。
- `src/domain/focused.ts`：復習専用・新規分野専用の候補作成、同題・同内容の除外、出題可能件数。`practiceScope.collection`で区別して保存し、10問・30問の不足は保存前に拒否する。
- `src/main.tsx`：診断・演習・模試、回答と自信度、見直し、結果、履歴、JSON入出力。
- `server/store.ts`：SQLite、問題版と出題時スナップショット、途中回答、提出、AI依頼・取り込み、バックアップ。
- `server/index.ts`：HTTP API、同一オリジン検証、教材とビルド成果物の配信。
- `server/cli.ts`：AI用結果出力、取り込み、内容検証の記録、バックアップ、状況確認。
- `materials/`：初期教材定義、収集済み教材定義、目視確認した例外。
- `scripts/`：公式PDFの取得・画像化、開発起動、独立したブラウザーテスト環境。

選択肢は表示順を固定し、問題IDと版、問題内容をセットへ保存する。正答は提出前のAPI応答から除外する。
個人学習用途であり、不正防止が必要な試験配信を目的としない。

## 教材の準備

2025年春期55問を基本教材とし、2016～2025年度の追加740問を収録する。
原本の図表を保持して問題部分を画像表示し、正答は公式解答へ対応させる。
OCRは主に問題番号の位置確認に使い、OCR本文を正確な問題文として表示しない。
全問の番号が順に一致する冊子だけを採用し、読めなかった例外は原本を目視してPDFハッシュ付きで記録する。

詳細解説・概念タグがあるのは基本教材55問。追加分の未分類・詳細解説未追加は明示する。
別年度に繰り返し出た同じ問題のグループ整理、古い法令等の現行範囲との精査、模試用の未着手教材の確保は未完了。

## 保存と再開

- 問題版と出題時スナップショットを保持する。教材の変更で当時の正答を置き換えない。
- 途中回答をAPI経由で保存し、保存状態を画面へ表示する。失敗時は再試行と控えのダウンロードができる。
- 更新版番号で、別タブからの古い回答の上書きを拒否する。
- 選択・移動は先に画面へ反映し、保存通信を直列化する。通信中の連続編集は最新のスナップショットにまとめ、古い応答で最新の編集を上書きしない。
- 回答確定・一括提出には最新の途中回答を同梱し、保存と採点を同じトランザクションで行う。実行中の途中保存だけを待ち、余分な保存の往復を挟まない。未確定の正答・解説は引き続きサーバーで隠す。
- 未保存のまま画面を閉じる際はブラウザーの確認を使う。オフライン学習や別タブとの自動マージは実装しない。
- 提出はトランザクションで確定し、同じ演習の再提出で履歴を増やさない。
- 診断・模試は終了日時を保存する。時間切れには最後に保存できた回答を確定し、再読込で延長しない。
- 未知の新しいDBスキーマは開かず、古いアプリで上書きしない。

## AIとの受け渡し

結果は `data/exports/<依頼ID>/learning-context.json` へ保存し、画面からもダウンロードできる。
依頼には集計、直近最大200件の対象科目の履歴、原本画像パス、利用可能教材、次セットのテンプレートを含める。
AI新規問題は必ず未検証として取り込み、内容検証を記録したものだけ出題する。

構造不正・未知の問題版・模試用問題・グループ重複を検出した場合はセット全体を拒否する。
取り込みは依頼IDで重複を防ぐ。出力後に提出が増えていれば最新履歴から作り直す。
開始時に未検証問題を除いた件数を示し、検証済み問題だけで演習する。

## 運用

`npm run build` の後に `npm start` で、APIとビルド成果物を127.0.0.1:3001から配信する。
`npm run dev` はAPIとViteを起動し、Viteから同じAPIへ転送する。
学習中に編集内容を即時反映させたくない場合は、本番ビルドで学習する。
切替前にテストとビルドを確認し、教材・DBをビルド成果物の外へ保持する。

`TRAINING_DATA_DIR` で保存先を変えられる。`data/` はGit管理外。
教材PNGはブラウザー内で1時間キャッシュし、次の問題画像を先読みする。内容ハッシュ付きのJS/CSSは長期キャッシュ、HTMLは毎回再検証、学習APIは`no-store`とする。静的ファイルはETagで再検証できる。
履歴がある起動時、稼働中24時間ごと、手動操作時に、SQLiteのVACUUM INTOで整合性のあるDBコピーとJSONを書き出す。
持ち出し・復元には `assets/` も必要。手順は [README](../README.md) を参照。

書込みAPIはJSON形式と接続元を検証する。認証・一般公開・複数ユーザー利用は初期範囲外。
外部AI APIの自動化、B科目、誤答理由の編集、細かな概念単位の復習期限は後続とする。
