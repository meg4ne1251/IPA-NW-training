# 技術構成

## 初期構成

React + TypeScript + Vite のブラウザーアプリ。npm lockfileで依存を固定し、Node.js 24 LTSを推奨する。
UIと出題・採点ロジックを分離し、Vitestで学習結果に関わる挙動を確認する。
CIでは npm ci → npm test → npm run build を実行する。

まず問題バンクをコードで管理し、構造を固めてからデータ管理機能を導入する。
サンプルの正答はクライアントに含まれる。学習用であり、不正防止が必要な試験配信には使用しない。

## 拡張方針

問題ID、年度、科目、分野、難易度、設問、正答、解説、根拠、レビュー状態を持つモデルへ拡張する。
選択式と事例記述式は異なる型にし、B科目は大問と小問を分ける。
出題時の問題版を保存して、後日の教材更新で過去の成績が変わらないようにする。

履歴はまず端末内保存。同期が必要になった時点でサーバーAPIとDBを選定する。
AI生成を導入する場合はAPIキーをサーバーで保持し、ブラウザーやGitに含めない。
公開・ホスティングは別の作業として選定する。今回の公開対象はGitHubのソースコード。
